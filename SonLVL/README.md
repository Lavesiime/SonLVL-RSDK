# SonLVL-RSDK

The main program in this repo, a full level editor for Retro Engine v3 and v4. This folder primarily deals with the GUI of the editor, while the [**SonLVLAPI** folder](SonLVLAPI) contains the code for actually dealing with the files.

See the [primary README](README.md#Building) for build instuctions.
